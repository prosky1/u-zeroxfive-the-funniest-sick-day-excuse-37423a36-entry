## The entry

> The gas station sushi I ate at 2 a.m. has taken my stomach hostage, and the ransom is a day off.

## How it works

`main.py` (Python 3) writes the excuse to `/output/entry.txt`, after guarding the competition gate: 1–200 UTF-8 characters, not blank, a single line, no leading or trailing white space — then reads the file back and verifies it byte for byte.

```sh
python3 main.py
```
